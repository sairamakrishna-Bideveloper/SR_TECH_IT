# SR_TECH_IT SEO Setup

This package adds SEO foundations: unique page titles and descriptions, robots.txt, sitemap.xml, Open Graph metadata, author/robots metadata, image alt text improvements, and Organization structured data.

## Before publishing
1. Upload all files to the GitHub repository root.
2. Open `sitemap.xml` and `robots.txt`. Replace `YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY` with the exact live GitHub Pages URL.
3. If you later connect a custom `.com` domain, update the sitemap and add canonical URLs using that final domain.
4. Add the live site to Google Search Console and submit `/sitemap.xml`.
5. Use URL Inspection to request indexing for the homepage and important course pages.

## Important
SEO does not guarantee first-page rankings. Google recommends useful, original, people-first content, descriptive titles, crawlable links, and accurate metadata.
